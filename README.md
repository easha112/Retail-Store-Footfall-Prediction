# Retail Store Footfall Prediction

This project predicts retail store visitor traffic using Machine Learning and Deep Learning models.

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Scikit-learn
* TensorFlow / Keras

## Features

The model predicts footfall based on:

* Hour of the day
* Day of the week
* Weekend indicator
* Peak shopping hours

## Models Used

* Random Forest Regressor
* Artificial Neural Network (ANN)

## Project Workflow

1. Simulate retail footfall dataset
2. Preprocess data and create features
3. Train ML and DL models
4. Evaluate models using RMSE
5. Predict future footfall trends

## Installation

```bash
pip install pandas numpy matplotlib scikit-learn tensorflow
```

## Run the Project

```bash
python footfall_prediction.py
```

## Output

The project:

* Generates simulated retail data
* Predicts customer footfall
* Compares actual vs predicted values
* Visualizes future predictions
